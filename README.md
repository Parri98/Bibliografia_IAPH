# Bibliografía IAPH · APA 7

Aplicación web estática para GitHub Pages.

## Funciones

- Generador guiado de referencias
- Corrección libre de una referencia completa pegada por el usuario
- Revisión de bibliografías completas, una referencia por línea
- Modos IAPH / revista PH y APA 7
- Cita breve en el texto
- Copia rápida de resultados

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css` y `app.js` a la raíz del repositorio.
3. Ve a `Settings > Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda.

## Autores

Introduce varios autores separados por punto y coma:

`Apellido, A.; Apellido, B.; Apellido, C.`

## Importante

La corrección automática está basada en reglas. Sirve como apoyo editorial, pero no sustituye una revisión manual en referencias incompletas o casos especiales.

## Archivos

- `index.html`: interfaz
- `style.css`: estilos
- `app.js`: lógica
